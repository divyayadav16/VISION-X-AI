# VISION-X | AI Computer Vision Intelligence Lab

VISION-X is an interactive computer vision application built with Python, Streamlit and YOLO11.

## Features
- Upload images for analysis
- Detect objects using YOLO11 Nano
- Display confidence scores
- Visualize detected objects with bounding boxes
- View object counts and analytics
- Download annotated detection images
- Adjust detection confidence threshold

## Technology Stack
- Python
- Streamlit
- Ultralytics YOLO11
- OpenCV
- Pandas
- Plotly
- Pillow

## Run Locally

Install dependencies:

    pip install -r requirements.txt

Launch the application:

    streamlit run app.py

## Project Status
Working prototype. Image-based object detection is implemented.
